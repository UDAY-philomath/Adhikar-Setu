# AdhikarSetu Intelligence Layer

The Intelligence Layer is responsible for the intelligent
processing and personalization features of AdhikarSetu.

## Responsibilities

- Eligibility matching
- Opportunity recommendation
- Opportunity knowledge base
- AI-assisted guidance
- Retrieval-Augmented Generation (RAG)

## Development Modules

### Eligibility

Determines whether a user matches the structured eligibility
criteria of an opportunity.

### Recommendation

Ranks relevant opportunities based on the user's profile,
role and eligibility.

### Knowledge Base

Stores structured information about opportunities and their
eligibility requirements.

### RAG

Retrieves relevant verified information to support the
AI assistant's responses.

## Processing Flow

User Profile
     ↓
Eligibility Engine
     ↓
Matching Opportunities
     ↓
Recommendation Engine
     ↓
AI Assistant / RAG
     ↓
User Guidance
